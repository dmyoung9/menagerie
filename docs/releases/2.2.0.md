# Release 2.2.0

This release brings significant work across the UI, backend, and resource-facts functionality.

Frontend updates include major improvements to the deployment wizard and resource management screens, new chart components for telemetry and capacity visualization, enhanced form controls and progress tracking, plus refined component composition and UI theming.

Backend changes expand resource tracking with comprehensive history, job management updates, manager refinements, and telemetry reporting improvements, alongside API schema adjustments.

Docs and tests are updated with comprehensive documentation, new frontend contract tests, and validation coverage.
