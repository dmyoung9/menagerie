# Menagerie 2.1.0

## Installation and deployment

- Add a versioned Linux x86_64 container image and an Unraid user template with
  persistent appdata, non-root execution, explicit dashboard networking, and no
  privileged mode or Docker socket.
- Include matching source and license inside the image. CPU and NVIDIA engine
  installation reuse the dashboard's existing managed-engine workflow.
- Publish the wheel, source archive, installer, Unraid template, locked dependency
  constraints and checksums together with a matching versioned container image.
- Tag-triggered publication waits for backend/frontend/plugin checks, installed
  artifact/privacy checks and synthetic container persistence/network acceptance.
  Runtime, package, installer and template versions must agree with the tag.

## Dashboard

- Adopt the shared Base UI design system and typed frontend contracts.
- Provide first-response guidance and a cancellable streaming test prompt without
  requiring a separate client. Explicit manual launch uncertainty is advisory;
  consent to unload another deployment remains required.
- Improve test isolation and distribution privacy checks.

## Support boundaries

Distribution remains private. This release does not change repository/package
visibility or upgrade an installed application automatically. Private registry
and GitHub release access must be arranged by an authorized administrator.

The application installer and managed binary discovery target Linux. Windows,
Intel/AMD acceleration, macOS, and additional image architectures are not newly
certified. Actual Unraid GPU/runtime acceptance is pending target-host testing;
container CI performs no inference. Use the checklist in `docs/unraid.md`.

The LAN dashboard has no authentication or TLS and is for trusted peers only.
Inference remains loopback-only, including with host-network containers. Back up
the registry before updating and preserve the `/data` mapping and its ownership.
See `docs/installation.md` and `docs/unraid.md` for installation and recovery.
