# Menagerie 2.1.4

## Telemetry collector resilience

The telemetry collector now stays alive when the model registry is locked,
instead of being taken down by a lock. Its health is surfaced via
`collector_status` and `collector_degraded` so staleness is visible in the
dashboard and CLI, while a clean collector cycle clears the last error and
emits a `collector_recovered` event.

## Limitations

Collector degradation is diagnostic only: it is shown as a status but does
not change `doctor`'s overall `ok` verdict or exit code, so a degraded
collector does not block other operations. Automated checks use isolated
synthetic data and fake workers, never real inference. No existing release
assets are replaced.
