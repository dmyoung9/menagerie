# Menagerie 2.1.3

## Optional Windows uninstaller cleanup

Download `menagerie-2.1.3-windows-x64-setup.exe` from this release's **Assets**.
Install it over the existing version to update the application and uninstaller;
an upgrade does not remove user data.

The Windows uninstaller now offers five independent removal options:

- Settings, saved model/engine references, history and registry backups.
- Menagerie-managed engines and source-build installations.
- Downloaded models in Menagerie's own `models\hf` cache.
- Engine/application caches, separate from model downloads.
- Application and runtime logs.

**All options are unchecked by default.** Leave them unchecked to keep existing
data for reinstallation. Selected files are permanently deleted, not moved to the
Recycle Bin. Removing settings loses saved references even if files remain;
removing engine/model files while retaining settings leaves references that need
repair. Imported files outside the selected application-owned locations are not
removed. See [Windows installation and recovery](../windows.md) for details.

## Safety and verification

- Cleanup is limited to the displayed state directory. Other custom state
  directories and external model/runtime paths are not searched.
- Busy state, directory links/junctions and unexpected file types prevent unsafe
  cleanup. Registry metadata is removed last to preserve recovery information
  when earlier file removal fails. Unknown files and small lock/ownership files
  may remain.
- Silent uninstall retains data unless specific categories and an additional
  confirmation are supplied. Cancelling the data-removal dialog keeps the app and
  data. Stopping or cleaning a never-launched state does not create new state.
- Native Windows CI verifies the compiled dialog's unchecked defaults and Cancel,
  each cleanup category/all categories, explicit confirmation, retained external
  files and junction refusal, alongside existing installed-app checks.

## Limitations

The installer remains unsigned. Clean Windows 11 / RTX 5060 acceptance, actual
security prompts, GPU acceleration and hardware telemetry remain pending
target-host verification. Automated checks use isolated synthetic data and fake
workers, never real inference. No existing release assets are replaced.
