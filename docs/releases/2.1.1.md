# Menagerie 2.1.1

## Dashboard

- Removed the first-response tour from Overview.
- Moved the Deployments section above the GPU/memory summary tiles.
- Overview keeps the same health, catalog and action behavior; no API changes.

## Limitations

- Installed 2.1.1 wheels and source archives ship the dashboard built from this
  revision. Running a new wheel requires a restart for the service to pick up
  the new assets.
- Real GPU acceptance remains separate from these UI changes.
